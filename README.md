# PyRus (ПайРус)

**PyRus** — это легковесный компилятор исходного кода (транслятор типа source-to-source), разработанный на базе интерпретатора Python и предназначенный для выполнения скриптов с русскоязычным синтаксисом.

Проект разработан как образовательный инструмент, позволяющий снизить синтаксический барьер при изучении базовых алгоритмов программирования, и поставляется в виде независимой системной утилиты.

Основное расширение файлов исходного кода: `.pr`

---

## Архитектура и принцип работы

Интерпретатор PyRus функционирует по принципу трансляции (транспиляции) кода:

1. **Лексический анализ и парсинг:** Утилита командной строки `pr.exe` принимает на вход файл с расширением `.pr` и считывает его текстовое содержимое в кодировке UTF-8.
2. **Синтаксическое сопоставление:** Парсер выполняет потоковую замену зарезервированных ключевых слов и встроенных функций языка PyRus на их семантические эквиваленты в стандартном синтаксисе Python. При этом структура отступов, имена пользовательских переменных и строковые литералы остаются неизменными.
3. **Генерация целевого кода:** Результат трансляции сохраняется в новый файл с расширением `.py` в той же директории, обеспечивая полную переносимость и совместимость с любой стандартной средой выполнения Python.

## Таблица соответствия синтаксиса

Компилятор обрабатывает следующие базовые токены и операторы управления потоком данных:

| Ключевое слово PyRus | Эквивалент в Python | Функциональное назначение |
| :--- | :--- | :--- |
| `если ` | `if ` | Условный оператор |
| `иначе_если ` | `elif ` | Альтернативное ветвление |
| `иначе:` | `else:` | Ветка кода по умолчанию |
| `для ` | `for ` | Цикл со счётчиком (итератор) |
| `пока ` | `while ` | Цикл с предусловием |
| `функция ` | `def ` | Объявление пользовательской функции |
| `вывод()` / `вывести()` | `print()` | Функция вывода данных в стандартный поток (stdout) |
| `ввод()` / `спросить()` | `input()` | Функция чтения данных из стандартного потока ввода (stdin) |
| `целое()` | `int()` | Приведение типа к целому числу |
| `дробное()` | `float()` | Приведение типа к числу с плавающей точкой |
| `строка()` | `str()` | Приведение типа к строке |
| `вернуть ` | `return ` | Возврат значения из функции |
| `Истина` | `True` | Булево значение (True) |
| `Ложь` | `False` | Булево значение (False) |

## Пример работы транслятора

### Исходный код на языке PyRus (`program.pr`):
```text
вывести("Запуск компилятора PyRus")

имя = спросить("Введите имя пользователя: ")
статус = спросить("Введите статус (Админ/Гость): ")

если статус == "Админ":
    вывести(f"Доступ разрешен. Приветствую, {имя}.")
иначе:
    вывести(f"Ограниченный доступ для пользователя {имя}.")
```

### Результат трансляции (`program.py`):
```python
print("Запуск компилятора PyRus")

имя = input("Введите имя пользователя: ")
статус = input("Введите статус (Админ/Гость): ")

if статус == "Админ":
    print(f"Доступ разрешен. Приветствую, {имя}.")
else:
    print(f"Ограниченный доступ для пользователя {имя}.")
```

## Развертывание и использование в системе

Для обеспечения интеграции с операционной системой Windows проект компилируется в независимый исполняемый файл `pr.exe` и упаковывается с помощью инсталлятора Inno Setup.

### Автоматическая интеграция:
При установке через `PyrusSetup.exe` программа автоматически вносит изменения в системный реестр (HKEY_CURRENT_USER\Software\Classes), связывая расширение `.pr` с утилитой `pr.exe`. Это позволяет выполнять трансляцию файлов двойным кликом мыши.

### Использование через интерфейс командной строки (CLI):
После добавления пути к исполняемому файлу в системную переменную `Path`, запуск транслятора выполняется из любой рабочей директории следующей командой:

```bash
pr имя_файла.pr
```

В результате работы в текущей папке будет сгенерирован готовый к исполнению скрипт `имя_файла.py`.
