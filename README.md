#PyRus#
PyRus — это простой интерпретатор кода с русским синтаксисом, созданный на основе Python. Он предназначен для обучения, чтобы убрать языковой барьер при изучении основ программирования и алгоритмов. Программа работает самостоятельно: она собирает и запускает код прямо в оперативной памяти, не требуя установки дополнительных инструментов и не создавая лишних файлов.

Файлы кода на PyRus имеют расширение `.pr`.

Архитектура и принцип работы

Интерпретатор PyRus переводит и запускает код "на лету", прямо в памяти. Вот как это происходит:

1.  Чтение кода: Программа `pr.exe` берёт файл `.pr`, читает его содержимое в кодировке UTF-8.
2.  Анализ и замена: Специальный парсер заменяет русские ключевые слова и функции PyRus на их аналоги в обычном Python. Отступы, циклы, имена переменных и текст остаются без изменений.
3.  Запуск в памяти: Полученный код не сохраняется. Транслятор передаёт его специальному движку, который выполняет программу в оперативной памяти и сразу выводит результат в консоль.

Сводная таблица синтаксиса

Интерпретатор поддерживает следующие основные команды и структуры:

PyRus | Python | Назначение
------- | -------- | --------
если | if | Проверка условия
иначе_если | elif | Другое условие, если первое не сработало
иначе: | else: | Действие по умолчанию, если условия выше не выполнены
для | for | Цикл для перебора элементов
пока | while | Цикл, пока условие истинно
функция | def | Создание своей функции
вывод() / вывести() | print() | Показать что-нибудь на экране
ввод() / спросить() | input() | Получить данные от пользователя
целое() | int() | Преобразовать в целое число
дробное() | float() | Преобразовать в число с дробной частью
строка() | str() | Преобразовать в текст
вернуть | return | Отдать значение из функции
Истина | True | Значение "правда"
Ложь | False | Значение "ложь"

Пример программы (`program.pr`)

Вот как выглядит простая программа на PyRus:

вывести("Привет!")

имя = спросить("Как тебя зовут? ")
статус = спросить("Ты Админ или Гость? ")

если статус == "Админ":
    вывести(f"Привет, {имя}. Доступ разрешен.")
иначе:
    вывести(f"Привет, {имя}. У тебя ограниченный доступ.")

Когда вы запустите этот файл, интерпретатор незаметно переведёт его в Python, выполнит и покажет результат в консоли, не показывая никаких технических деталей.

Установка и использование

Чтобы программа нормально работала в Windows, её собирают в файл `pr.exe` и упаковывают с помощью инсталлятора Inno Setup.

Автоматическая установка:
Если запустить `PyrusSetup.exe`, программа сама добавит нужные записи в системный реестр. Это позволит запускать `.pr` файлы прямо из командной строки.

Использование через командную строку:
Если добавить папку с `pr.exe` в системную переменную `Path`, можно будет запускать скрипты из любой папки такой командой:

pr имя_файла.pr
