# PyRus (ПайРус)

**PyRus** — это простой интерпретатор кода с русским синтаксисом, созданный на основе ядра Python. 

Проект предназначен для использования в образовательных целях. Его главная задача — убрать языковой барьер у начинающих разработчиков при изучении основ программирования и базовых алгоритмов. Программа работает полностью самостоятельно: она транслирует и запускает код прямо в оперативной памяти, не требуя установки дополнительных инструментов и не создавая лишних промежуточных файлов на жестком диске.

Основное расширение файлов исходного кода: `.pr`

---

## Архитектура и принцип работы

Интерпретатор PyRus обрабатывает и запускает исходный код «на лету» в изолированной среде памяти. Этот процесс делится на три основных этапа:

1. **Чтение кода:** Системная утилита командной строки `pr.exe` принимает на вход файл с расширением `.pr` и считывает его текстовое содержимое в стандартной кодировке UTF-8.
2. **Анализ и замена токенов:** Специальный синтаксический парсер находит зарезервированные русские ключевые слова и функции PyRus, после чего заменяет их на семантические аналоги из стандартного Python. При этом структура отступов, логика циклов, имена пользовательских переменных и строковые литералы остаются нетронутыми.
3. **Запуск в памяти:** Полученный после трансляции код не сохраняется на диск. Интерпретатор мгновенно передает его встроенному виртуальному движку выполнения (`exec`), который обрабатывает программу в оперативной памяти и сразу выводит результат в стандартный поток консоли.

## Сводная таблица синтаксиса

Интерпретатор поддерживает следующие основные команды и структуры управления потоком данных:

| Ключевое слово PyRus | Эквивалент в Python | Функциональное назначение |
| :--- | :--- | :--- |
| `если ` | `if ` | Проверка условия (условный оператор) |
| `иначе_если ` | `elif ` | Альтернативное условие, если первое ложно |
| `иначе:` | `else:` | Действие по умолчанию, если условия выше не выполнены |
| `для ` | `for ` | Цикл со счётчиком для перебора элементов |
| `пока ` | `while ` | Цикл, выполняющийся пока условие истинно |
| `функция ` | `def ` | Объявление пользовательской функции |
| `вывод()` / `вывести()` | `print()` | Вывод информации на экран (stdout) |
| `ввод()` / `спросить()` | `input()` | Получение текстовых данных от пользователя (stdin) |
| `целое()` | `int()` | Преобразование типа данных в целое число |
| `дробное()` | `float()` | Преобразование типа данных в число с дробной частью |
| `строка()` | `str()` | Преобразование типа данных в текст (строку) |
| `вернуть ` | `return ` | Возврат результирующего значения из функции |
| `Истина` | `True` | Логическое значение «правда» (Boolean True) |
| `Ложь` | `False` | Логическое значение «ложь» (Boolean False) |

## Пример программы (`program.pr`)

Ниже представлен пример синтаксически корректного скрипта на языке PyRus:

```text
вывести("Привет!")

имя = спросить("Как тебя зовут? ")
статус = спросить("Ты Админ или Гость? ")

если статус == "Admin":
    вывести(f"Привет, {имя}. Доступ разрешен.")
иначе:
    вывести(f"Привет, {имя}. У тебя ограниченный доступ.")
```

При запуске этого файла интерпретатор скрывает под капотом все технические детали трансформации: он незаметно переведет структуру в память, выполнит алгоритм и сразу покажет итоговый результат в окне терминала.

## Установка и развертывание

Для корректной интеграции и работы внутри операционной системы Windows исходный код компилируется в независимый исполняемый файл `pr.exe` и упаковывается с помощью инсталлятора Inno Setup.

### Автоматическая установка:
При запуске дистрибутива `PyrusSetup.exe` программа автоматически вносит необходимые конфигурационные записи в системный реестр (`HKEY_CURRENT_USER\Software\Classes`). Это связывает расширение `.pr` с интерпретатором и позволяет вызывать утилиту напрямую.

### Использование через интерфейс командной строки (CLI):
После добавления папки с исполняемым файлом `pr.exe` в системную переменную среды `Path`, вы можете запускать свои скрипты из любой рабочей директории одной короткой командой:

```bash
pr имя_файла.pr
```
